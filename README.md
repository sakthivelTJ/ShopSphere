# ShopSphere 🛒

A full-stack e-commerce web application built with **Spring Boot 3**, **Hibernate / JPA**, **JDBC**, and **JSP** views.

## 🚀 Features
- **User Authentication**: Login, registration, role-based access.
- **Product Management**: Category filter, search, inventory tracking.
- **Shopping Cart & Checkout**: Interactive cart management and order placement.
- **Admin Dashboard**: Sales reporting, inventory management, user oversight.

## 🛠️ Tech Stack
- **Backend**: Spring Boot 3.2.5 (Java 17), Spring Data JPA, Spring MVC
- **Frontend**: JSP (Jakarta Taglibs / JSTL), CSS3, JavaScript
- **Database**: MySQL

## 📦 Running Locally
1. Clone the repository:
   ```bash
   git clone https://github.com/sakthivelTJ/ShopSphere.git
   ```
2. Configure your MySQL connection details in `src/main/resources/application.properties`.
3. Run the application:
   ```bash
   mvn spring-boot:run
   ```
4. Access the application in your browser at `http://localhost:8080`.
